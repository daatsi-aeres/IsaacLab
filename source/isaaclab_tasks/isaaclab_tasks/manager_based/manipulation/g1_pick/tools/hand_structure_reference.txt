7. KEY OBSERVATIONS FOR HAND REPLACEMENT
================================================================================

a) The hands are separate sub-trees attached via PhysicsFixedJoint (AssemblerFixedJoint).
   The attachment point is: wrist_yaw_link -> hand_base_link with a specific offset.

b) The USD uses Isaac Sim's "Assembler" pattern:
   - g1_left_hand_inspire_left_physics/left_hand  (left hand sub-articulation)
   - g1_right_hand_inspire_right_physics/right_hand (right hand sub-articulation)

c) Mimic joints use PhysxMimicJointAPI:rotZ (NOT software mimic in the env cfg).
   However, the env cfg ALSO implements software mimic via InspireMimicAction.
   The USD mimic gearings are: thumb_inter=-1.6, thumb_distal=-2.4, fingers=-1.0
   The software mimic gearings are: thumb_inter=0.8024, thumb_distal=0.8024*0.9487, fingers=1.0843
   NOTE: These are DIFFERENT ratios — the software mimic overrides the USD mimic.

d) USD joint drive stiffness/damping are VERY LOW (e.g., stiffness ~0.2, damping ~0.00008).
   The env cfg overrides these with the ImplicitActuatorCfg:
   - right_hand: stiffness=100.0, damping=0.5, effort_limit=30.0
   Isaac Lab's implicit actuator settings OVERRIDE the USD joint drive values.

e) Attachment offset for right hand: localPos0 = (0.0415, -0.003, ~0)
   Attachment offset for left hand:  localPos0 = (0.0415, +0.003, ~0)
   Only the Y component is mirrored between left and right.

f) The pelvis is fixed to the world via RootFixedJoint at z=-0.8671216.
